## Notes for a successor

- Dev-server HMR churn (other agents compiling routes) makes Turbopack send `turbopack-message type=restart` + `reloadPage "HMR hash mismatch"` every ~0.5 s → every open page reloads in a loop and networkidle never settles. Blocking /_next/hmr entirely prevents hydration; tooling/qa/bughunt/fixes/_dev-stable.ts (`isolateHmr(ctx)` + `stableGoto(page, url)`) drops only the reload-type frames — all web_visual verify scripts use it.

- Files in packages/storefront/src/shell/{header,footer,mobile-nav}.tsx and the tenant layout.tsx are CRLF in the working tree — edit them EOL-safely (multi-line string replaces written with LF line breaks silently do not match).
- Node on Windows cannot resolve *.localhost: HTTP checks use 127.0.0.1:3000 with a Host header (see SS-07-08-10-verify.ts); Playwright resolves them fine.
