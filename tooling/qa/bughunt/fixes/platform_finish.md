## Follow-ups for other packets

- **ops / .env.example owner**: document `TRUSTED_PROXY` (number of reverse-proxy hops that append to X-Forwarded-For: 1 for nginx/Caddy/Vercel, 2 for Cloudflare + proxy; unset = X-Forwarded-For ignored, X-Real-IP used). Without it in production behind a proxy that only sets X-Forwarded-For, the per-IP OTP limit is skipped (per-target limits still apply).
- **admin editor (apps/admin/src/components/editor/auto-form.tsx:188)**: image fields offer `accept="image/*"` (SVG pickable); uploads go through uploadBrandAsset, which now refuses SVG with a clear error — narrowing the accept list there (`image/png,image/jpeg,image/webp,image/gif,image/avif`) would avoid the round trip.
