## API for the admin Domains page (ADMIN_B2-11) — `import { ... } from "@rentweb/core/tenant"`

Source: `packages/core/src/tenant/domains.ts`. All functions take the admin db (`getAdminDb()`), never throw for business errors.

```ts
normalizeDomainInput(raw: string): string                 // "https://WWW.Shop.COM/x" -> "www.shop.com"
validateCustomHostname(hostname: string): string | null   // Thai error or null (also rejects *.<rootDomain>)
domainDnsInstructions(hostname, token, tenantSlug)        // { txt:{name:"_rentweb.<host>", value: token}, cname:{name: host, value:"<slug>.<root>"} }
claimCustomDomain(db, tenantId, rawHostname): Promise<
  | { ok: true; domain: { id; hostname; status: "pending"; verificationToken } }
  | { ok: false; code: "invalid" | "platform" | "taken" | "duplicate"; error: string }>
  // "taken"  = another tenant has it ACTIVE (verified). Another tenant's pending/failed claim does NOT block.
  // "duplicate" = this tenant already added it.
verifyCustomDomain(db, tenantId, domainId, opts?: { resolver?: DomainDnsResolver }): Promise<
  | { ok: true; status: "active"; hostname: string; message: string }
  | { ok: false; status: "failed" | "pending"; code: "not_found" | "not_custom" | "txt_missing" | "cname_mismatch" | "taken"; hostname?: string; error: string }>
  // TXT `_rentweb.<host>` must equal the claim's own verificationToken (proves DNS ownership) AND
  // CNAME -> <slug>.<root> | cname.<root> (or apex A record in EDGE_IPS). On success: status active,
  // other tenants' non-active claims of the same host -> failed ("ยืนยันโดยร้านอื่นแล้ว"), host cache invalidated.
removeCustomDomain(db, tenantId, domainId): Promise<{ ok: true; hostname } | { ok: false; error }>  // + host cache invalidation
isRoutableDomainStatus(status): boolean                   // only "active" routes
```

Storefront routing: `resolveTenantByHost` only joins `tenant_domains.status = 'active'`.
DB: `tenant_domains_hostname_uq` is now a partial unique index `WHERE status = 'active'` + `tenant_domains_tenant_host_uq (tenant_id, hostname)`,
so several tenants may hold pending claims; only one can ever be active.
