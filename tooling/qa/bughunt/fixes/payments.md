## Follow-ups for other packets

- **commerce** — (1) register `registerPaymentClosedHandler("order", …)` that cancels the still-unpaid order whose current payment (metadata.paymentId) expired/was voided, restocks and releases the coupon (COR-33 stock release; contract in payments-api.md §3.2). (2) `cancelUnpaidOrder` + admin cancel flows: void open payments with `cancelPayment(tx, tenantId, id, reason, { runHandler: false })` instead of the raw `UPDATE payments SET status=cancelled`. (3) `onOrderPaid`: return `refundRequired(reason)` when the order is not payable (the built-in target check already covers cancelled/refunded). (4) admin payments/order UI: show `paymentRefundRequired(payment)`. (5) NOTE: `packages/modules/commerce/test/orders.test.ts` "onOrderPaid ... customer stats" currently fails on `email: null` (+ the next test as a cascade, the failing tx rolls back) because of the in-flight `upsertGuestCustomer` change in packages/core/src/customer/index.ts by the customer/OTP packet — not caused by this packet (my commerce change is payload fields only).
- **booking** — closed handlers for `booking` (cancel the pending booking → frees the slot) and `patient_package`; cancel/reschedule should `cancelPayment(…, { runHandler: false })` the open deposit payment.
- **restaurant** — closed handlers for `reservation` (cancel pending reservation) and `rest_order` (unpaid pickup order; table-session bill → clear session.paymentId, status back to open). `approveOrderPayment(cash)` / mark-cash paths should use `cancelPayment` instead of `markFailed("ชำระเงินสดแทน")` so the superseded QR can never be re-approved (markPaid default accepts failed for admin re-approval).
- **storefront** (packages/storefront/src/payments/payment-panel.tsx) — pass the page proof explicitly: add a prop with the access key / phone and send it as form field `k`/`p` on the slip upload and as `?k=`/`?p=` on the status poll (today it works through the same-origin Referer, which a strict Referrer-Policy or privacy extension can strip → 403/404). Show the 403/409 error text.
- **admin uploads** (apps/admin/src/app/t/[slug]/{media,design,products,services,restaurant/menu,topup/_shared}) — validate with `sniffImage()` (and derive ext/mime from it) instead of the client `file.type`/`file.name`; SVG logos remain allowed by IMAGE_MIMES but are neutralised by the /uploads CSP sandbox.
- **topup** (out of scope, nothing changed) — to enable expiry for top-ups register closed handlers for `topup` / `wallet_topup`; `adminApproveSlip` keeps working (markPaid default still accepts failed/expired).
- **db** — optional index `payments (status, expires_at)` for the cross-tenant expiry sweep.
- **customer/OTP packet** — SEC-006 OTP half (`randomOtp()` in packages/core/src/crypto.ts) is theirs.
